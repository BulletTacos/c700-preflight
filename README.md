# C700 Preflight Calculator

Takeoff/landing, weights, fuel, climb, winds aloft, terrain and weather planning for the Cessna Citation Longitude (Model 700) in Microsoft Flight Simulator 2024.

Live site: https://bullettacos.github.io/c700-preflight/

Performance figures are **estimates** scaled from Textron published specifications (takeoff field length 4,810 ft, landing distance 3,170 ft, 4,310 fpm climb, 483 KTAS max cruise, 14,500 lb usable fuel) and limits from the MSFS Model 700 Operators Guide. For flight simulation only; not for real-world flight.
